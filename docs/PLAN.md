## Approved decisions

1. MartHub is single-vendor with one inventory location.
2. One Product represents one sellable SKU; variants are outside the MVP.
3. Cart and wishlist require authentication.
4. Ratings, reviews, coupons, online payments, returns, and refunds are outside the MVP.
5. Shipping uses a server-configured fixed fee and free-shipping threshold.
6. COD checkout decrements stock when the order is created; cancellation restores it exactly once.
7. The MVP supports a light visual theme only.
8. Web and API use the same origin through `/api/v1`.
9. Homepage campaigns use a minimal Promotion model rather than hard-coded promotional content.
10. Delivery context represents address or region and shipping eligibility; it does not change stock in the one-warehouse MVP.
11. Wishlist is presented within `/account/my-items?tab=reorder|wishlist`; order history remains separate.
12. Planning documents and canonical reference filenames are persisted before implementation.

## Definition of Done for every task

A task may be marked `[x]` only when all of the following are true:

- Its acceptance criteria are satisfied without relying on unfinished future tasks.
- Required automated checks pass, or an explicitly listed manual check is completed.
- Relevant loading, empty, error, disabled, authorization, and responsive states are covered where applicable.
- API, schema, migration, UX, and environment documentation affected by the task are updated.
- No secrets, sensitive tokens, copied reference assets, or unexplained console/server errors are introduced.
- Verification evidence is recorded in this document.
- Changes remain inside the active task's scope.
